这个页面会自动检测微信登录状态，未登录时自动跳转授权。

💡 使用说明：
1. 在微信中打开此页面：https://carture.matrix-net.tech/wechat/demo
2. 如果未登录会自动跳转到微信授权页面
3. 授权后会自动返回并显示用户信息
4. 再次访问时会直接显示已保存的用户信息

📖 自动授权流程

1. 访问检测

页面加载时自动执行以下检测流程：

  • 检查URL参数中是否有授权回调信息
  • 检查本地存储中是否有有效用户信息
  • 验证是否在微信浏览器环境中
  • 自动发起授权或显示用户信息

2. 用户信息缓存

授权成功后，用户信息会保存到 localStorage，包含24小时过期机制。

3. 授权重定向

授权完成后会自动重定向回当前页面，并携带用户信息参数。

// 自动授权检测流程
1. checkAuthFromURL() - 检查URL回调参数
2. getUserInfoFromStorage() - 检查本地缓存
3. isWechatBrowser() - 验证微信环境
4. autoStartWechatAuth() - 自动发起授权

🔗 API 接口

服务器提供以下API接口供前端调用：

// 获取单个用户信息
GET /api/user/{openid}

// 获取所有用户列表  
GET /api/users

// 微信授权流程
GET /wechat/auth           - 发起授权
GET /wechat/callback       - 授权回调
