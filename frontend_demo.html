🔐 微信登录集成示例

这个页面演示了前端如何获取微信登录后的用户信息

✅ 登录成功

🚀 开始微信登录

选择一种登录方式：

直接跳转登录

iframe 登录

📖 实现说明

方法1: 直接跳转

用户点击登录后直接跳转到微信授权页面，授权完成后微信会回调到我们的服务器，服务器返回包含用户信息的HTML页面。

方法2: 弹窗登录

使用 window.open() 打开登录页面，通过 postMessage 接收用户信息。

方法3: iframe 登录

在页面中嵌入 iframe，通过 postMessage 通信获取用户信息。

方法4: 从 localStorage 读取

登录成功后，用户信息会自动保存到 localStorage，页面可以随时读取。

// 从 localStorage 读取用户信息
const userInfo = localStorage.getItem('wechat_user_info');
if (userInfo) {
    const user = JSON.parse(userInfo);
    console.log('用户信息:', user);
}

🔗 API 接口

服务器提供以下API接口供前端调用：

// 获取单个用户信息
GET /api/user/{openid}

// 获取所有用户列表  
GET /api/users

// 微信授权流程
GET /wechat/auth           - 发起授权
GET /wechat/callback       - 授权回调
