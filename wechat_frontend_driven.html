🔄 前端驱动流程

  1. 前端构建授权链接 - 直接构建微信OAuth URL
  2. 获取授权码 - 微信回调返回code参数
  3. 发送code到后端 - 调用 POST /api/wechat/auth
  4. 检查授权状态 - 调用 GET /api/user/{openid}

🔗 后端API接口

// 1. 通过code获取用户信息
POST /vista/wechat/api/auth
Content-Type: application/json
{
  "code": "微信授权码",
  "state": "可选状态参数"
}

// 2. 查询用户信息和授权状态
GET /vista/wechat/api/user/{openid}

响应：
{
  "code": 200,
  "data": {
    "exists": true,          // 用户是否存在
    "need_auth": false,      // 是否需要重新授权
    "user_info": { ... }     // 用户详细信息
  }
}

⚡ 优势

  • ✅ 前端控制 - 授权流程完全由前端控制
  • ✅ 接口简洁 - 后端只有两个核心接口
  • ✅ 状态检查 - 智能判断是否需要重新授权
  • ✅ 易于集成 - 适配任何前端框架
